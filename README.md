# BMW — исходная версия

Исходный BMW-сайт из Figma с фоновым видео, до адаптации под сообщество FAM.

- `main` — эта исходная BMW-версия.
- `feature_fam` — актуальная FAM-версия с клубными ссылками, встречами и фотографиями.

Файлы сайта находятся в корне: `index.html`, `styles.css`, `app.js`, `assets/`. Их можно отдавать любым статическим сервером, включая GitHub Pages.

Для локального просмотра: `npm run dev`, затем http://127.0.0.1:4173. Проверка JavaScript: `npm run check`.

Видео длительностью 25 секунд экспортировано из исходной Figma и хранится локально в `assets/background.mp4`. Настройки уменьшения движения останавливают воспроизведение. Интерфейс представляет концепт; подключения к автомобилю и платёжных операций нет.
