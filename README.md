# FAM — BMW-клуб Санкт-Петербурга

Клубная визитка на основе BMW-кокпита из ветки `main`. Основная страница содержит прямые ссылки на канал и чат клуба, анонсы встреч, медиа, барахолку и другие ресурсы. Даты будущих встреч публикуются в [канале FAM](https://t.me/famcrsclub).

## Локальный запуск

Запустите `npm run dev` и откройте http://127.0.0.1:4173. Команда `npm run check` проверяет синтаксис JavaScript. Сайт статический и публикуется из корня ветки `feature_fam`.

Фон запускается без звука при загрузке и использует оригинальный MP4 1440 × 1024. Видеофайл загружается сразу при открытии страницы. Значок на первом экране позволяет приостановить фон.
