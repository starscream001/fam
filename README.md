# FAM — BMW-клуб Санкт-Петербурга

Клубная визитка на основе BMW-кокпита из ветки `main`. Основная страница содержит прямые ссылки на канал и чат клуба, анонсы встреч, медиа, барахолку и другие ресурсы. Даты будущих встреч публикуются в [канале FAM](https://t.me/famcrsclub).

## Локальный запуск

Запустите `npm run dev` и откройте http://127.0.0.1:4173. Команда `npm run check` проверяет синтаксис JavaScript. Сайт статический и публикуется из корня ветки `feature_fam`.

Фон использует клубный ролик «1122 (3)(1)» в разрешении 1080 × 1920, 60 кадров/с. Для браузеров подготовлены H.264 MP4 с быстрым стартом и запасной WebM. Фоновое видео воспроизводится без звука. До запуска виден кадр встречи. Если плеер зависает на старте, скрипт пробует загрузить MP4 обычным HTTP-запросом и воспроизвести локальную копию. Параметр `?video-check` показывает состояние плеера на устройстве.

Сайт использует комбинированное оформление с видео на тёмном первом экране и молочными разделами. Чтобы включить цели переходов в Яндекс Метрике, укажите номер своего счётчика в `analytics.js`.

## Публикация новостей

Откройте `_club/stories.html` в ветке `feature_fam`. Скопируйте любой блок `<article>…</article>` в начало контейнера `.stories`. Замените дату в `datetime` (ГГГГ-ММ-ДД), её видимую подпись, заголовок, текст и ссылку «Смотреть в Telegram». Для собственной новости без Telegram-поста эту ссылку можно удалить. Фото и видео можно положить в `assets/` и указать путь в статье.

Ближайший запуск синхронизации подготовит страницы для GitHub Pages. Карточка с машиной показывает четыре самые свежие статьи по дате. Ранние записи сохраняются в архиве по четыре на страницу. Архив загружается при переходе по ссылке «Открыть архив». При одинаковой дате выше будет запись, стоящая первой в файле. Адрес последних четырёх новостей — https://fambmw.ru/news.html.

### Автоматическая лента

Сценарий `scripts/sync_news.py` читает только публичный канал famcrsclub. За расписание отвечает `.github/workflows/fam-news.yml` в ветке по умолчанию main. Записи сопоставляются по номеру поста. Повторная загрузка сохраняет архив и обновляет изменённые тексты. Если Telegram недоступен, задача завершается до публикации и сайт продолжает отдавать последнюю удачную версию. Отсутствие поста в публичном окне само по себе не удаляет его из архива.

Фото и небольшие видео из новых постов сохраняются локально, новые фото также появляются в галерее. Ближайшая встреча выводится при распознанном явном анонсе с датой. Время, место, карта и условия добавляются, только если их удалось выделить из публикации. Оригинал всегда доступен по ссылке.

По умолчанию сайт берёт текст канала. Для необязательного подбора заголовков через ИИ задайте в GitHub Actions переменные FAM_AI_URL (HTTPS API с поддержкой chat completions), FAM_AI_MODEL и секрет FAM_AI_KEY. Принимается только фраза, встречающаяся в исходной публикации. При ошибке модели используется заголовок из текста.
